# Security Policy

## Supported Versions

Because this application serves as an active clinical digital health prototype for the Wellcome Snakebite Innovation Prize and the National Institutes of Health (NIH), Pakistan, only the latest live production build is actively maintained and monitored for security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this platform handles structural frameworks meant for emergency public health coordination, maintaining software integrity is critical. If you discover a security vulnerability, please do **NOT** open a public GitHub issue. Instead, report it privately to ensure safety.

### How to Report
Please submit all vulnerability findings directly via email to:  
📩 **buisnessonly85@gmail.com**

To help expedite the review process, please include:
1. A detailed description of the vulnerability and its potential exposure risk.
2. Step-by-step instructions or a proof-of-concept (PoC) script to reproduce the behavior.
3. The specific device/browser environment where the vulnerability was verified.

### What to Expect
* **Initial Response:** You will receive an automated or manual acknowledgment within **48 hours** confirming that your report was received.
* **Status Updates:** A status update on whether the vulnerability is accepted, under review, or declined will be provided within **7 days**.
* **Resolution:** If accepted, a patch will be deployed directly to the main production branch, and credit will be given in the repository change logs if requested.

Thank you for helping keep this emergency public health intervention safe and secure.
